# Samuel Stephen Raj — Portfolio

A responsive static portfolio inspired by the supplied Cyera reference website. The design borrows its oversized editorial typography, dark canvas, atmospheric gradients, fine borders, and floating glass panels, while using original portfolio-specific content and CSS illustrations.

## Run locally
Open `index.html` in a browser. No build step is required.

## Add your profile photo
1. Add a portrait photo to this folder: `assets/profile.jpg`
2. Use a square or portrait-oriented image with your face clearly visible.
3. Refresh `index.html`. The hero profile card will use the image instead of the initials fallback.

## Update links
The résumé PDF is included as `Samuel-Stephen-Raj-Resume.pdf`. Add your real GitHub and LinkedIn profile URLs when ready. The résumé only listed the platform names, not their URLs, so those links have intentionally not been invented.

## Deploy
You can publish this static site with GitHub Pages or Netlify. Upload the folder contents to a repository and enable GitHub Pages, or drag the folder into Netlify Drop.

## Accuracy note
The skill progress bars are decorative and are explicitly labelled as visual styling, not formal ratings. Project cards describe the projects in the supplied résumé and do not pretend to link to live demos.

The portfolio entry describes destination exploration, destination details, location-aware experiences, weather information, and an AI-assisted itinerary planner. The listed stack reflects the project setup discussed during development: React, Vite, React Router, OpenWeather, Google Gemini, and an Express backend.
